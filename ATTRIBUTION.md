# Reference credits

This is an unofficial fan-made companion inspired by Shigure Ui. Character identity belongs to its respective creator and rights holders.

The generated artwork and choreography were informed by these references supplied during the project:

- [Original tiny dancing-pet example](https://x.com/calif_io/status/2113570095549337977)
- [YouTube dance reference](https://www.youtube.com/watch?v=til1yw6eJio)
- [YouTube short reference](https://www.youtube.com/shorts/4cZLMe_WzEM)
- [Pinterest visual reference](https://www.pinterest.com/pin/981855156250007750/)
- [Petdex Shigure Ui dance example](https://petdex.dev/pets/shigure-ui-dance)

User-supplied motion references were named `Shigure Ui_1.gif`, `Shigure Ui_2.gif`, `Shigure Ui_dance.gif`, and a Shigure Ui dance MP4. The idle update uses the opening side-sway cycle, waiting uses the hand-to-mouth sway, and working uses six chronological poses from the longer dance. See the [format notes](docs/animation-format.md) for the selected frame indices.

The included canonical art and strips were generated with OpenAI's built-in image-generation tool. The original and More Dancing options retain the same approved character identity.
